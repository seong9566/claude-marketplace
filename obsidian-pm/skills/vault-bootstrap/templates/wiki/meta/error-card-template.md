# 에러 카드 템플릿

`wiki/errors/`의 에러 해결 기록은 단순 로그가 아니라 "다음에 같은 문제를 만났을 때 바로 검색되는 해결 카드"여야 한다.

```markdown
# <에러 이름>

> 한 줄 요약.

- 발생일: YYYY-MM-DD
- 관련 기술: ...
- 관련 프로젝트: ...

## 증상

- 에러 메시지 / 재현되는 현상

## 원인

## 해결

- 단계별 해결 방법 (그대로 따라 할 수 있게)

## 재현 조건

- 어떤 상황에서 다시 발생하는가

## 연결 문서

- [[sources/...]] / [[topics/...]]
```
