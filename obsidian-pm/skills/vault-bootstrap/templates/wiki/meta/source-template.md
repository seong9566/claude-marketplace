# source 페이지 템플릿

`wiki/sources/`의 원본별 요약 페이지는 아래 구조를 따른다. 원본 1개당 1페이지.

```markdown
# 원본 제목

> 한 줄 요약.

- 원본 파일: `raw/...`
- 처리일: YYYY-MM-DD
- 유형: dev | docs | article | error | snippet | project | asset | other
- 관련 기술: ...
- 관련 프로젝트: ...

## 요약

## 핵심 주장

## 중요한 세부사항

## 개발 관점 (재사용 포인트)

- 저장 이유 / 현재 작업과의 연결 / 어디에 재사용할지

## 새로 만들거나 갱신한 연결 문서

- [[topics/...]] / [[harness/...]] / [[entities/...]]

## 후속 질문
```
