# 사용자 불만 페이지 양식 (product/pain-points/<market>.md)

> `wiki/product/pain-points/<market>.md` 작성용. 앱 리뷰·Reddit·커뮤니티에서 발견한 **실제 불만(문제 증거)만** 출처와 함께 모은다. 해법·아이디어는 여기 말고 가설로. 아래 블록 복사.

```markdown
# 불만: <시장> 시장

> 한 줄: <이 시장의 가장 큰 문제 한 문장>

## 상위 불만 (빈도·강도순)

### 1. <불만 요지>
- 증거: "<리뷰/글 인용>" — 출처(앱리뷰/Reddit/커뮤니티), raw/market-research/...
- 빈도/강도: <얼마나 자주·심각한가>
- 관련 JTBD: <어떤 일이 막히나>

### 2. <불만 요지>
- ...

## 근거 원본
- raw/market-research/... · [[sources/...]]

## 연결
- 시장: [[product/markets/<market>]] · 가설: [[product/hypotheses/...]] (이 불만에서 나온)
```

## 채우는 법
- **문제만** 적는다 — 해법은 [[product/hypotheses/...]]로. (philosophy: 문제 중심)
- 같은 불만이 여러 출처에서 반복되면 강한 신호.
