# Wiki Index

이 vault의 탐색 시작점. 큰 변경이 있을 때마다 갱신한다.

## 운영

- `AGENTS.md` — 운영 스키마(폴더 구조·핵심 규칙·작업 절차·양식)
- `wiki/log.md` — 시간순 작업 기록
- `wiki/meta/` — 템플릿(page / source / error card / project / task / frontmatter)

## 제품 발굴 (`wiki/product/`)

_아직 없음. 시장·경쟁·페인포인트·가설이 쌓이면 여기에 링크한다._

## 프로젝트 (`wiki/projects/`)

_아직 없음. 검증 통과 후보를 승격하면 여기에 링크한다._

## 지식 레이어

- `wiki/topics/` — 반복 개념
- `wiki/dev/` — 재사용 개발 노트
- `wiki/harness/` — agent rules·검증 루프·체크리스트
- `wiki/errors/` — 에러 해결 카드
- `wiki/questions/` — 재사용 가치 있는 질문·답변
- `wiki/sources/` — 원본별 요약
- `wiki/entities/` — 도구·조직·제품
